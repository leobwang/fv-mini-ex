# H060 · Random-walk martingales: cheatsheet

Exercise: [`problem.lean`](problem.lean).
Lean companion: [`guide.lean`](guide.lean). Entry **Rn** here is
example **Rn** there. Put the cursor after each tactic to see the same before and after states in the
infoview. Generic tactics are in [`TACTIC_STATES.md`](../../../TACTIC_STATES.md).

**Assumed:** Lean basics (easy tier E001–E033: `intro`, `exact`, `apply`, `have`, `rcases`, `calc`,
`funext`, `simp`, `rw`), and measure-theoretic probability on paper (σ-algebras, conditional expectation,
independence, martingales). **New here:** how Mathlib writes all of that: measurability relative to a
σ-algebra, filtrations, `Integrable`, the conditional expectation `μ[f | m]`, almost-everywhere equality
`=ᵐ[μ]`, independence, and the martingale criterion for discrete time.

## How to read an entry

Each entry is one tactic or one lemma used with `rw`/`have`/`apply`/`refine`. It says what changes
(**goal**, **context**, or **goal list**), lists the placeholders with their types, then shows the proof
state before and after.

- `Γ ⊢ G` is a proof state: hypotheses `Γ`, goal `G`. A cell shows only the hypotheses that change.
- `P` is "the rest of your goal" (`P : α → Prop`). The step changes only the part inside `P (…)`, wherever it
  sits in a larger goal. `G : Prop` is an arbitrary goal, and `k : … → G` only consumes a new hypothesis:
  such an entry shows what `have h := …` puts into the context.
- Placeholders are written as Lean binders. `{Ω : Type}` is the sample space. `[mΩ : MeasurableSpace Ω]` is
  its ambient σ-algebra (in the exercise it is anonymous and prints as `inst✝ : MeasurableSpace Ω`).
  `m m' m₁ m₂ : MeasurableSpace Ω` are further σ-algebras on the same `Ω`. `(μ : Measure Ω)` is a measure;
  `[IsProbabilityMeasure μ]` says `μ Ω = 1`.
- Every `⊢` cell is a state Lean reaches in the companion file; `tools/guide_sync.py` checks that. A state
  containing `|` (absolute value, conditional expectation) cannot sit in a table cell, so it is shown in a
  `lean-goal` block, or, for a hypothesis, as plain code with the `|` escaped. A hypothesis that contains
  `, ` (such as an integral `∫ (x : Ω), f x ∂μ`) is likewise shown as its own code span next to `⊢ G`.

## Reading the goals

Write `Sₙ` for `fun ω => ∑ i ∈ Finset.range (n + 1), X i ω` and `ℱₙ` for `Filtration.natural X hX n`.

| You see | It means |
|---|---|
| `Finset.range k` | the finite set `{0, 1, …, k - 1}` of naturals |
| `∑ i ∈ Finset.range (n + 1), X i ω` | `X 0 ω + ⋯ + X n ω`; the bound variable may be renamed (`∑ x ∈ …`) |
| `Ω : Type u_1` | `Ω` is a type; `u_1` is a universe level (from `Type*` in the statement), ignorable here |
| `\|x\|` | the absolute value of `x : ℝ` |
| `↑n` | the natural number `n` cast into `ℝ`; `↑(n + 1)` and `↑n + 1` are different terms (R15) |
| `i.succ` | `i + 1` |
| `m ≤ m'` (σ-algebras) | `m ⊆ m'`: every `m`-measurable set is `m'`-measurable (`m` is coarser, "knows less") |
| `Filtration ℕ mΩ` | a sequence of σ-algebras `𝓕 0 ≤ 𝓕 1 ≤ ⋯`, each `≤ mΩ` |
| `↑𝓕 i`, `↑(Filtration.natural X hX) n` | the σ-algebra at time `i` (a filtration is coerced to a function `ℕ → MeasurableSpace Ω`) |
| `Filtration.natural X hX` | the natural filtration `ℱₙ = σ(X 0, …, X n)`; `hX` (each `X i` measurable) is needed to build it |
| `MeasurableSpace.comap f Real.measurableSpace` | `σ(f) = {f⁻¹(B) \| B Borel}`, the σ-algebra generated by `f : Ω → ℝ`; `Real.measurableSpace` is the Borel σ-algebra of `ℝ` (printed `inferInstance` where the guide writes it so) |
| `Measurable f`, `StronglyMeasurable f` | `f` is measurable; strongly measurable = pointwise limit of simple functions. For `f : Ω → ℝ` the two agree (R7, R11) |
| `StronglyMeasurable[m] f` | measurable with respect to `m`, not `mΩ`. **The infoview prints this as `StronglyMeasurable f`**: the `[m]` is hidden (Traps) |
| `AEStronglyMeasurable f μ` | `f` equals a strongly measurable function outside a `μ`-null set |
| `StronglyAdapted 𝓕 f` | `∀ n, StronglyMeasurable[𝓕 n] (f n)`: the process is adapted |
| `Integrable f μ` | `f` is a.e.-strongly measurable and `∫ ‖f‖ dμ < ∞` |
| `‖r‖` | the norm; for `r : ℝ` it is `\|r\|` (R21) |
| `∫ (x : Ω), f x ∂μ` | `E[f]`. You type it as `μ[f]`; the infoview always prints the integral |
| `μ[f \| m]` | `E[f \| m]`, the conditional expectation: an `m`-measurable function `Ω → ℝ`, unique up to a.e. equality |
| `f =ᵐ[μ] g` | `f ω = g ω` for `μ`-almost every `ω` |
| `∀ᵐ (x : Ω) ∂μ, p x` | `p x` holds outside a `μ`-null set |
| `iIndepFun X μ` | the random variables `X 0, X 1, …` are mutually independent under `μ` |
| `Indep m₁ m₂ μ` | `μ (A ∩ B) = μ A · μ B` for all `A ∈ m₁`, `B ∈ m₂` |
| `Martingale f 𝓕 μ` | `f` is adapted, each `f n` integrable, and `E[f j \| 𝓕 i] =ᵐ f i` for `i ≤ j` |
| `f - g`, `f * g`, `f ^ 2`, `0` on functions | pointwise: `(f * g) ω = f ω * g ω`, `0 ω = 0` (R20, R40) |
| `fun x => 0` vs `0` | the same function, written two ways; `exact` accepts one for the other, `rw` does not |
| `S : ℕ → Ω → ℝ := …` | a local definition made by `set` (R25) |
| `case hadp`, `case hint`, `case hf` | the three goals left by R17: adapted, integrable, increments |

## Part 1 · `partial_sum_adapted` (milestone 1)

Statement: `Sₙ` is `ℱₙ`-measurable. Each `X i` with `i ≤ n` is `ℱᵢ`-measurable, `ℱᵢ ≤ ℱₙ`, and a finite sum of
measurable functions is measurable.

**R1 · `apply Finset.stronglyMeasurable_fun_sum`** changes the **goal**: measurability of a pointwise sum
becomes measurability of each summand. Lemma: `(∀ i ∈ s, StronglyMeasurable (f i)) → StronglyMeasurable fun a
=> ∑ i ∈ s, f i a` (for any `m`). Placeholders: `{ι : Type} {m : MeasurableSpace Ω} (s : Finset ι)
(f : ι → Ω → ℝ)`.

| Before | After |
|---|---|
| `⊢ StronglyMeasurable fun ω => ∑ i ∈ s, f i ω` | `⊢ ∀ i ∈ s, StronglyMeasurable (f i)` |

Then `intro i hi` gives `hi : i ∈ Finset.range (n + 1)`.

**R2 · `Finset.mem_range_succ_iff`** changes the **context** (`have h := Finset.mem_range_succ_iff.mp hi`).
Lemma: `a ∈ Finset.range b.succ ↔ a ≤ b`. Placeholders: `(i n : ℕ) (hi : i ∈ Finset.range (n + 1))`.

| Before | After |
|---|---|
| `⊢ G` | `h : i ≤ n ⊢ G` |

**R3 · `Filtration.stronglyAdapted_natural hY i`** changes the **context**: `Y i` is measurable for
`ℱᵢ = σ(Y 0, …, Y i)`. The lemma says `StronglyAdapted (Filtration.natural Y hY) Y`, a `∀ i`, so it can be
applied to `i`. Placeholders: `(Y : ℕ → Ω → ℝ) (hY : ∀ i, StronglyMeasurable (Y i)) (i : ℕ)`. The new
hypothesis *is* `StronglyMeasurable[Filtration.natural Y hY i] (Y i)`, but prints without the `[…]`.

| Before | After |
|---|---|
| `⊢ G` | `h : StronglyMeasurable (Y i) ⊢ G` |

**R4 · `(Filtration.natural Y hY).mono hij`** changes the **context**. `Filtration.mono : i ≤ j → 𝓕 i ≤ 𝓕 j`:
information only grows. Placeholders: as R3, plus `(i j : ℕ) (hij : i ≤ j)`.

| Before | After |
|---|---|
| `⊢ G` | `h : ↑(Filtration.natural Y hY) i ≤ ↑(Filtration.natural Y hY) j ⊢ G` |

**R5 · `refine hf.mono ?_`** changes the **goal**. `StronglyMeasurable.mono : StronglyMeasurable[m'] f →
m' ≤ m → StronglyMeasurable[m] f`: measurable for a coarser σ-algebra implies measurable for a finer one.
Placeholders: `{m m' : MeasurableSpace Ω} (f : Ω → ℝ) (hf : StronglyMeasurable[m'] f)`. Note that before the
step the hypothesis and the goal *print identically*; they differ only in the hidden σ-algebra.

| Before | After |
|---|---|
| `hf : StronglyMeasurable f ⊢ StronglyMeasurable f` | `⊢ m' ≤ m` |

## Part 2 · `increment_condExp` (milestone 2)

Statement: `μ[X (n + 1) | ℱₙ] =ᵐ[μ] 0`. The next step is independent of the past, so conditioning on the
past gives its plain mean, which is `0`. This is one application of R6; R7–R12 build its four arguments.

**R6 · `condExp_indep_eq`** changes the **context** (`have h := condExp_indep_eq hle₁ hle₂ hf hind`). Lemma:
`m₁ ≤ mΩ → m₂ ≤ mΩ → StronglyMeasurable[m₁] f → Indep m₁ m₂ μ → μ[f | m₂] =ᵐ[μ] fun _ => μ[f]`. Read `m₁`
as "the information in `f`" and `m₂` as "what we condition on". Placeholders: `[mΩ : MeasurableSpace Ω]
{μ : Measure Ω} [IsProbabilityMeasure μ] {m₁ m₂ : MeasurableSpace Ω} (f : Ω → ℝ)`. (It also needs `μ`
σ-finite on `m₂`, which Lean finds by itself for a probability measure.)

| Before | After |
|---|---|
| `⊢ G` | `⊢ G`, plus `h : μ[f \| m₂] =ᵐ[μ] fun x => ∫ (x : Ω), f x ∂μ` |

For the exercise: `f := X (n + 1)`, `m₁ := σ(X (n + 1))`, `m₂ := ℱₙ`.

**R7 · `hf.measurable`** changes the **context**. `StronglyMeasurable.measurable : StronglyMeasurable f →
Measurable f`. Placeholders: `(f : Ω → ℝ) (hf : StronglyMeasurable f)`.

| Before | After |
|---|---|
| `⊢ G` | `h : Measurable f ⊢ G` |

**R8 · `hf.comap_le`** changes the **context**. `Measurable.comap_le : Measurable f → MeasurableSpace.comap f
mβ ≤ mΩ`: `σ(f)` is a sub-σ-algebra when `f` is measurable. This is `hle₁` of R6. Placeholders:
`(f : Ω → ℝ) (hf : Measurable f)`.

| Before | After |
|---|---|
| `⊢ G` | `h : MeasurableSpace.comap f Real.measurableSpace ≤ mΩ ⊢ G` |

**R9 · `𝓕.le i`** changes the **context**. `Filtration.le : 𝓕 i ≤ mΩ`. This is `hle₂` of R6 (write
`Filtration.le _ n` to let Lean find the filtration). Placeholders: `(𝓕 : Filtration ℕ mΩ) (i : ℕ)`.

| Before | After |
|---|---|
| `⊢ G` | `h : ↑𝓕 i ≤ mΩ ⊢ G` |

**R10 · `comap_measurable f`** changes the **context**: `f` is `σ(f)`-measurable, by definition of `σ(f)`.
Lemma: `Measurable[m.comap f] f`. Placeholders: `(f : Ω → ℝ)`. The `[…]` is hidden again.

| Before | After |
|---|---|
| `⊢ G` | `h : Measurable f ⊢ G` |

**R11 · `hf.stronglyMeasurable`** changes the **context**. `Measurable.stronglyMeasurable : Measurable f →
StronglyMeasurable f` for `ℝ`-valued `f`, with respect to the same σ-algebra. R10 then R11 is `hf` of R6.
Placeholders: `{m : MeasurableSpace Ω} (f : Ω → ℝ) (hf : Measurable[m] f)`.

| Before | After |
|---|---|
| `⊢ G` | `h : StronglyMeasurable f ⊢ G` |

**R12 · `hind.indep_comap_natural_of_lt hY hij`** changes the **context**. `iIndepFun.indep_comap_natural_of_lt
: (∀ i, StronglyMeasurable (Y i)) → iIndepFun Y μ → i < j → Indep (MeasurableSpace.comap (Y j) _)
(Filtration.natural Y hY i) μ`: a future variable is independent of the past. This is `hind` of R6, in the
order R6 wants. `Nat.lt_succ_self i : i < i.succ` supplies `i < i + 1`. Placeholders:
`(Y : ℕ → Ω → ℝ) (hY : ∀ i, StronglyMeasurable (Y i)) (hind : iIndepFun Y μ) (i : ℕ)`.

| Before | After |
|---|---|
| `⊢ G` | `h : Indep (MeasurableSpace.comap (Y i.succ) Real.measurableSpace) (↑(Filtration.natural Y hY) i) μ ⊢ G` |

**R13 · `rw [hm] at h`** changes the **context**: it rewrites inside the hypothesis `h` instead of the goal.
Here it replaces the mean by `0`. Placeholders: `(f g : Ω → ℝ) (hm : μ[f] = 0)`.

| Before | After |
|---|---|
| `h : g =ᵐ[μ] fun x => ∫ (x : Ω), f x ∂μ`, `⊢ G` | `h : g =ᵐ[μ] fun x => 0 ⊢ G` |

Then `exact h` closes a goal `… =ᵐ[μ] 0`: `0` and `fun x => 0` are the same function (Traps).

## Part 3 · `sq_increment` (milestone 3)

Statement: pure algebra in `ℝ`. With `s = ∑ i ∈ range (n + 1), X i` and `x = X (n + 1)`, and `x² = 1`:
`(s + x)² - (n + 2) - (s² - (n + 1)) = 2 s x`.

**R14 · `rw [Finset.sum_range_succ _ (n + 1)]`** changes the **goal**. Lemma: `Finset.sum_range_succ f n :
∑ x ∈ range (n + 1), f x = ∑ x ∈ range n, f x + f n`. Giving `n + 1` as the second argument makes it rewrite
only `range (n + 1 + 1)`; the shorter sum is left alone. Placeholders: `(f : ℕ → ℝ) (n : ℕ)
(P : ℝ → ℝ → Prop)`.

| Before | After |
|---|---|
| `⊢ P (∑ i ∈ Finset.range (n + 1 + 1), f i) (∑ i ∈ Finset.range (n + 1), f i)` | `⊢ P (∑ x ∈ Finset.range (n + 1), f x + f (n + 1)) (∑ i ∈ Finset.range (n + 1), f i)` |

**R15 · `push_cast`** changes the **goal**: it moves casts `ℕ → ℝ` inward, so `↑(n + 1)` becomes `↑n + 1`.
Placeholders: `(n : ℕ)`.

| Before | After |
|---|---|
| `⊢ P ↑(n + 1)` | `⊢ P (↑n + 1)` |

**R16 · `linear_combination h`** **closes** a goal `a = b` when `a - b - c·(lhs h - rhs h)` is `0` as a
commutative-ring identity (here `c = 1`; write `linear_combination 3 * h` etc. for other coefficients).
`ring` cannot use hypotheses; `linear_combination` is `ring` plus a multiple of an equation.
Placeholders: `(s x : ℝ) (h : x ^ 2 = 1)`.

| Before | After |
|---|---|
| `h : x ^ 2 = 1 ⊢ (s + x) ^ 2 - 1 = s ^ 2 + 2 * s * x` | no goals |

## Part 4 · `walk_martingale`

Statement: `Martingale (fun n ω => ∑ i ∈ Finset.range (n + 1), X i ω) (Filtration.natural X hX) μ`. Uses
milestones 1 and 2.

**R17 · `apply martingale_of_condExp_sub_eq_zero_nat`** changes the **goal list**: one goal becomes three.
Lemma: `StronglyAdapted 𝓕 f → (∀ i, Integrable (f i) μ) → (∀ i, μ[f (i + 1) - f i | 𝓕 i] =ᵐ[μ] 0) →
Martingale f 𝓕 μ` (discrete time, finite measure): it suffices that each one-step increment has conditional
expectation `0`. Placeholders: `(𝓕 : Filtration ℕ mΩ) (f : ℕ → Ω → ℝ)`.

| Before | After |
|---|---|
| `⊢ Martingale f 𝓕 μ` | `⊢ StronglyAdapted 𝓕 f`, `⊢ ∀ (i : ℕ), Integrable (f i) μ`, and the goal below |

```lean-goal
⊢ ∀ (i : ℕ), μ[f (i + 1) - f i | ↑𝓕 i] =ᵐ[μ] 0
```

**R18 · `intro n` on `StronglyAdapted 𝓕 f`** changes the **goal and context**: `StronglyAdapted` is a `∀ n`
under its name, so `intro` sees through it. Likewise a term `fun n => …` or a lemma with a last argument
`n` (milestone 1 applied to `X hX`) proves it directly. Placeholders: `(𝓕 : Filtration ℕ mΩ)
(f : ℕ → Ω → ℝ)`. The goal means `StronglyMeasurable[𝓕 n] (f n)`.

| Before | After |
|---|---|
| `⊢ StronglyAdapted 𝓕 f` | `n : ℕ ⊢ StronglyMeasurable (f n)` |

**R19 · `apply integrable_finsetSum`** changes the **goal**: a finite sum is integrable when every summand
is. Lemma: `(s : Finset ι) → (∀ i ∈ s, Integrable (f i) μ) → Integrable (fun a => ∑ i ∈ s, f i a) μ`. As a
term: `integrable_finsetSum _ fun i _ => …`. Placeholders: `{ι : Type} (s : Finset ι) (f : ι → Ω → ℝ)`.

| Before | After |
|---|---|
| `⊢ Integrable (fun ω => ∑ i ∈ s, f i ω) μ` | `⊢ ∀ i ∈ s, Integrable (f i) μ` |

**R20 · `Pi.sub_apply`** changes the **goal**. Lemma: `(f - g) ω = f ω - g ω`. `simp` applies it by itself;
it is what turns the goal after `funext ω` into arithmetic. Placeholders: `(f g : Ω → ℝ) (ω : Ω)`.

| Before | After |
|---|---|
| `⊢ P ((f - g) ω)` | `⊢ P (f ω - g ω)` |

**W1: an increment by `funext` + `simp`.** For the doubled walk `Tₙ = ∑ᵢ 2 Yᵢ`, `funext ω` gives the
pointwise goal, and `simp [Finset.sum_range_succ _ (n + 1)]` (R20, R14) closes it:

```lean-goal
⊢ ((fun ω => ∑ i ∈ Finset.range (n + 1 + 1), 2 * Y i ω) - fun ω => ∑ i ∈ Finset.range (n + 1), 2 * Y i ω) = fun ω => 2 * Y (n + 1) ω
⊢ ((fun ω => ∑ i ∈ Finset.range (n + 1 + 1), 2 * Y i ω) - fun ω => ∑ i ∈ Finset.range (n + 1), 2 * Y i ω) ω = 2 * Y (n + 1) ω
```

In the exercise, state the increment as a `have e : (fun ω => …) - (fun ω => …) = X (n + 1)` exactly as it
appears in the `hf` goal, then `rw [e]`.

## Part 5 · `walk_sq_martingale`

Statement: for `±1` steps, `Sₙ² - (n + 1)` is a martingale. There is no `hint` hypothesis: integrability
comes from boundedness (`|X i| ≤ 1`, `|Sₙ| ≤ n + 1`). The increment is `2 Sₙ X (n + 1)` (milestone 3); pull
the `ℱₙ`-measurable factor `2 Sₙ` out of the conditional expectation and use milestone 2.

### Bounded, hence integrable

**R21 · `Real.norm_eq_abs`** changes the **goal**. Lemma: `‖r‖ = |r|` for `r : ℝ`. The two are equal by
definition, so a proof of `|f x| ≤ C` is accepted where `‖f x‖ ≤ C` is expected; rewrite when a later
lemma (R29) needs the `|·|` form. Placeholders: `(r : ℝ)`.

```lean-goal
⊢ P ‖r‖
⊢ P |r|
```

**R22 · `refine Integrable.of_bound hf C ?_`** changes the **goal**. Lemma: `AEStronglyMeasurable f μ →
∀ C, (∀ᵐ x ∂μ, ‖f x‖ ≤ C) → Integrable f μ`, for a finite measure (a probability measure is one): a bounded
measurable function is integrable. Placeholders: `(f : Ω → ℝ) (hf : AEStronglyMeasurable f μ) (C : ℝ)`.

| Before | After |
|---|---|
| `⊢ Integrable f μ` | `⊢ ∀ᵐ (x : Ω) ∂μ, ‖f x‖ ≤ C` |

**R23 · `apply StronglyMeasurable.aestronglyMeasurable`** changes the **goal**: measurable everywhere implies
measurable a.e. As a term: `hf.aestronglyMeasurable`. Placeholders: `(f : Ω → ℝ)`.

| Before | After |
|---|---|
| `⊢ AEStronglyMeasurable f μ` | `⊢ StronglyMeasurable f` |

**R24 · `apply ae_of_all μ`** changes the **goal**: true everywhere implies true almost everywhere. Lemma:
`ae_of_all μ : (∀ a, p a) → ∀ᵐ a ∂μ, p a`. As a term: `ae_of_all _ fun ω => …`. Placeholders:
`(μ : Measure Ω) (p : Ω → Prop)`.

| Before | After |
|---|---|
| `⊢ ∀ᵐ (x : Ω) ∂μ, p x` | `⊢ ∀ (a : Ω), p a` |

**W2: bounded by 3, hence integrable.** `refine Integrable.of_bound hf.aestronglyMeasurable 3 ?_` (R22, R23)
leaves the bound, and `exact ae_of_all μ fun ω => hb ω` (R24, with `hb : ∀ ω, |f ω| ≤ 3`) closes it:

| Before | After |
|---|---|
| `⊢ Integrable f μ` | `⊢ ∀ᵐ (x : Ω) ∂μ, ‖f x‖ ≤ 3` |

**R25 · `set S : T := e with hS`** changes the **context and goal**: it adds a local definition `S := e` and
an equation `hS : S = e`, and replaces `e` by `S` wherever `e` occurs literally (goal *and* hypotheses). Use it
to name the walk `S n ω`. In `walk_sq_martingale` the goal never contains `fun n ω => ∑ …` on its own (it sits
inside `fun n ω => (∑ …) ^ 2 - …`), so the goal keeps showing the sum (Traps). Placeholders: `(g : ℕ → ℝ)
(P : (ℕ → ℝ) → Prop)`.

| Before | After |
|---|---|
| `h : P fun n => g n + 1 ⊢ P fun n => g n + 1` | `T : ℕ → ℝ := fun n => g n + 1, h : P T, hT : T = fun n => g n + 1 ⊢ P T` |

**R26 · `Finset.abs_sum_le_sum_abs f s`** changes the **context**: the triangle inequality for finite sums,
`|∑ i ∈ s, f i| ≤ ∑ i ∈ s, |f i|`. First step of the `calc` for `|Sₙ| ≤ n + 1`. Placeholders:
`{ι : Type} (s : Finset ι) (f : ι → ℝ)`.

| Before | After |
|---|---|
| `⊢ G` | `⊢ G`, plus `h : \|∑ i ∈ s, f i\| ≤ ∑ i ∈ s, \|f i\|` |

**R27 · `apply Finset.sum_le_sum`** changes the **goal**: compare two sums over the same set term by term.
Lemma: `(∀ i ∈ s, f i ≤ g i) → ∑ i ∈ s, f i ≤ ∑ i ∈ s, g i`. As a term: `Finset.sum_le_sum fun i _ => …`.
Second step of the `calc` (with `g i = 1` and `hb`). Placeholders: `{ι : Type} (s : Finset ι) (f g : ι → ℝ)`.

| Before | After |
|---|---|
| `⊢ ∑ i ∈ s, f i ≤ ∑ i ∈ s, g i` | `⊢ ∀ i ∈ s, f i ≤ g i` |

**R28 · `simp` on a constant sum** changes the **goal**: `∑ i ∈ range k, (1 : ℝ)` becomes `↑k` (via
`Finset.sum_const`, `Finset.card_range`). Last step of the `calc`; `simp` also turns `↑(n + 1)` into `↑n + 1`.
Placeholders: `(k : ℕ)`.

| Before | After |
|---|---|
| `⊢ P (∑ x ∈ Finset.range k, 1)` | `⊢ P ↑k` |

### Integrability of `Sₙ²`

**R29 · `rw [abs_pow]`** changes the **goal**. Lemma: `|a ^ n| = |a| ^ n`. Placeholders: `(a : ℝ) (n : ℕ)`.

```lean-goal
⊢ P |a ^ n|
⊢ P (|a| ^ n)
```

**R30 · `refine pow_le_pow_left₀ ?_ ?_ 2`** changes the **goal list**. Lemma: `0 ≤ a → a ≤ b → ∀ n, a ^ n ≤
b ^ n`. When `a` is an absolute value, `abs_nonneg a : 0 ≤ |a|` proves the first side goal. Placeholders:
`(a b : ℝ)`.

| Before | After |
|---|---|
| `⊢ a ^ 2 ≤ b ^ 2` | `⊢ 0 ≤ a`, `⊢ a ≤ b` |

So the bound `‖Sₙ ω ^ 2‖ ≤ (n + 1) ^ 2` is R21, R29, then R30 with `abs_nonneg` and `hSb`.

### Building measurability and integrability terms

These are lemmas used with dot notation on a hypothesis (`hf.pow 2` means `StronglyMeasurable.pow hf 2`).
Each entry shows what `have h := …` adds. On functions, `f ^ 2`, `f - g`, `f * g` are pointwise, so
`f ^ 2 - fun x => c` is the same function as `fun ω => f ω ^ 2 - c`, and `exact` accepts one for the other.

**R31 · `(hf.pow 2).sub stronglyMeasurable_const`** changes the **context**. `StronglyMeasurable.pow :
StronglyMeasurable f → ∀ n, StronglyMeasurable (f ^ n)`, `StronglyMeasurable.sub : StronglyMeasurable f →
StronglyMeasurable g → StronglyMeasurable (f - g)`, `stronglyMeasurable_const : StronglyMeasurable fun _ => b`.
All three keep the σ-algebra of `hf`. Placeholders: `{m : MeasurableSpace Ω} (f : Ω → ℝ) (c : ℝ)
(hf : StronglyMeasurable[m] f)`.

| Before | After |
|---|---|
| `⊢ G` | `h : StronglyMeasurable (f ^ 2 - fun x => c) ⊢ G` |

**R32 · `hf.pow 2`** (`AEStronglyMeasurable.pow`) changes the **context**: the a.e. version of `.pow`.
Placeholders: `(f : Ω → ℝ) (hf : AEStronglyMeasurable f μ)`.

| Before | After |
|---|---|
| `⊢ G` | `h : AEStronglyMeasurable (f ^ 2) μ ⊢ G` |

**R33 · `hf.sub (integrable_const c)`** changes the **context**. `Integrable.sub : Integrable f μ →
Integrable g μ → Integrable (f - g) μ`; `integrable_const c : Integrable (fun _ => c) μ` (finite measure).
Placeholders: `(f : Ω → ℝ) (c : ℝ) (hf : Integrable f μ)`.

| Before | After |
|---|---|
| `⊢ G` | `h : Integrable (f - fun x => c) μ ⊢ G` |

**R34 · `hf.const_mul c`** (`Integrable.const_mul`) changes the **context**. Placeholders:
`(f : Ω → ℝ) (c : ℝ) (hf : Integrable f μ)`.

| Before | After |
|---|---|
| `⊢ G` | `h : Integrable (fun x => c * f x) μ ⊢ G` |

**R35 · `hf.mul_bdd hg hgC`** (`Integrable.mul_bdd`) changes the **context**: integrable times bounded
measurable is integrable. Lemma: `Integrable f μ → AEStronglyMeasurable g μ → (∀ᵐ x ∂μ, ‖g x‖ ≤ C) →
Integrable (fun x => f x * g x) μ`. With `f := fun ω => 2 * S n ω` this is the `hfg` argument of R37.
Placeholders: `(f g : Ω → ℝ) (C : ℝ)`.

| Before | After |
|---|---|
| `⊢ G` | `h : Integrable (fun x => f x * g x) μ ⊢ G` |

**R36 · `hf.const_mul c`** (`StronglyMeasurable.const_mul`) changes the **context**, keeping the σ-algebra of
`hf`. With `hf := hSm n` it says `2 Sₙ` is `ℱₙ`-measurable: the `hf` argument of R37. Placeholders:
`{m : MeasurableSpace Ω} (f : Ω → ℝ) (c : ℝ) (hf : StronglyMeasurable[m] f)`.

| Before | After |
|---|---|
| `⊢ G` | `h : StronglyMeasurable fun x => c * f x ⊢ G` |

### Pulling out what is known, and working pointwise

**R37 · `condExp_mul_of_stronglyMeasurable_left hf hfg hg`** changes the **context**: "taking out what is
known", `E[f g | m] = f E[g | m]` a.e. when `f` is `m`-measurable. Lemma: `StronglyMeasurable[m] f →
Integrable (f * g) μ → Integrable g μ → μ[f * g | m] =ᵐ[μ] f * μ[g | m]`. The product must be the function
product `f * g` (Traps). Placeholders: `{m mΩ : MeasurableSpace Ω} (f g : Ω → ℝ)`.

| Before | After |
|---|---|
| `⊢ G` | `⊢ G`, plus `h : μ[f * g \| m] =ᵐ[μ] f * μ[g \| m]` |

**R38 · `refine h.trans ?_`** changes the **goal**. `Filter.EventuallyEq.trans : f =ᵐ g → g =ᵐ h → f =ᵐ h`
chains a.e. equalities: after the pull-out (R37) the goal becomes "the pulled-out form is `0` a.e.".
Placeholders: `(a b c : Ω → ℝ) (h : a =ᵐ[μ] b)`.

| Before | After |
|---|---|
| `h : a =ᵐ[μ] b ⊢ a =ᵐ[μ] c` | `⊢ b =ᵐ[μ] c` |

**R39 · `filter_upwards [h] with ω hω`** changes the **goal and context**: an a.e. goal becomes a pointwise
goal at a generic `ω`, with the pointwise form of each listed a.e. fact. (It works because finitely many
"a.e." facts hold together a.e.) Placeholders: `(u v F G : Ω → ℝ) (h : u =ᵐ[μ] v)`.

| Before | After |
|---|---|
| `h : u =ᵐ[μ] v ⊢ F =ᵐ[μ] G` | `ω : Ω, hω : u ω = v ω ⊢ F ω = G ω` |

**R40 · `Pi.mul_apply`, `Pi.zero_apply`** change the **goal**: `(f * g) ω = f ω * g ω` and
`(0 : Ω → ℝ) ω = 0`. `simp [hω]` applies both and then `hω`. Placeholders: `(f g : Ω → ℝ) (ω : Ω)
(P : ℝ → ℝ → Prop)`.

| Before | After |
|---|---|
| `⊢ P ((f * g) ω) (0 ω)` | `⊢ P (f ω * g ω) 0` |

**W3: a product with an a.e.-zero factor is a.e. zero.** From `h : u =ᵐ[μ] 0`, `filter_upwards [h] with ω hω`
(R39) leaves the pointwise goal, and `simp [hω]` (R40) closes it:

| Before | After |
|---|---|
| `h : u =ᵐ[μ] 0 ⊢ g * u =ᵐ[μ] 0` | `ω : Ω, hω : u ω = 0 ω ⊢ (g * u) ω = 0 ω` |

## Traps

- **Hidden σ-algebras.** `StronglyMeasurable[ℱ n] f` and `StronglyMeasurable f` (for `mΩ`) print the same.
  `hSm n : StronglyMeasurable (S n)` in the context is about `ℱₙ`. To get the `mΩ` version, `.mono` it with
  `Filtration.le` (R5, R9). Write the σ-algebra out in a `have` type when you state such a fact.
- **`μ[f]` prints as an integral.** `hmean i : μ[X i] = 0` shows as `∫ (x : Ω), X i x ∂μ = 0`; `rw [hmean]`
  still finds it inside R6's result (R13).
- **`0` and `fun x => 0`.** R6 + R13 give `… =ᵐ[μ] fun x => 0`, the goal says `… =ᵐ[μ] 0`. They are the same
  function, so `exact h` works, but `rw` treats them as different text.
- **`condExp_indep_eq` argument order.** `m₁` is the σ-algebra of the variable, `m₂` the conditioning one,
  and the independence must be `Indep m₁ m₂`; R12 produces exactly `Indep σ(X j) ℱᵢ`.
- **Which sum `Finset.sum_range_succ` rewrites.** Plain `rw [Finset.sum_range_succ]` rewrites the first match,
  which may be the shorter sum. Give the index: `Finset.sum_range_succ _ (n + 1)` (R14).
- **Casts.** The square-walk goal has `↑(n + 1) + 1` where you may expect `↑n + 1 + 1`: the `n + 1` is a
  natural number cast as a whole. `push_cast` (R15) fixes it before `linear_combination`.
- **Shape of the increment.** R37 needs the function product `(fun ω => 2 * S n ω) * X (n + 1)`. State `e`
  with that right-hand side; `fun ω => 2 * S n ω * X (n + 1) ω` is equal but `rw`/R37 will not match it.
- **`‖·‖` versus `|·|`.** `Integrable.of_bound` and `mul_bdd` speak about `‖·‖`; on `ℝ` it is `|·|` by
  definition, so `hb i ω` fits directly. `rw [Real.norm_eq_abs]` (R21) only when a rewrite such as `abs_pow`
  needs the `|·|` form.
- **`set` rewrites only literal occurrences** (R25), in hypotheses too. In `walk_sq_martingale` it leaves the
  goal alone, so the three goals after R17 still show `∑ i ∈ Finset.range (n + 1), X i ω`, not `S n ω`. They
  are equal by definition: `exact` accepts a term about `S`, and `e` may be stated with `S n ω` or with the
  sum copied from the goal (`rw [e]` matches either).
- **Unreduced lambdas.** After R17 + `intro n` the `hadp` goal reads
  `StronglyMeasurable ((fun n ω => …) n)`: the function applied to `n`, not yet simplified. `exact` sees
  through it; `beta_reduce` shows the simplified form if you want to read it.
- **Banned:** `condExp_natural_ae_eq_of_lt` would prove milestone 2 in one line; build it from R6 instead.
