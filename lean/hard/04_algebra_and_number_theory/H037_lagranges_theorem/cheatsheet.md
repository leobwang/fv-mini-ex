# H037 · Lagrange's theorem: cheatsheet

Exercise: [`problem.lean`](problem.lean).
Lean companion: [`guide.lean`](guide.lean). Entry **Rn** here is
example **Rn** there. Put the cursor after each tactic to see the same before and after states in the
infoview. Generic tactics are in [`TACTIC_STATES.md`](../../../TACTIC_STATES.md).

**Assumed:** Lean basics (easy tier E001–E033): `def`, `theorem`, `intro`, `exact`, `have`, `rw`,
`simp`, `constructor`, anonymous constructors `⟨…⟩`, `∃`/`∧`/`↔`. **New here:** Mathlib's groups and
subgroups (`Group`, `Subgroup`, `x ∈ H`), finite sets `Finset` with `#s`, `univ`, `filter`, `image` and
`∑`, the three notions of "finite" (`Finite`, `Fintype`, `Finset`) and their three cardinalities
(`Nat.card`, `Fintype.card`, `#`), decidability instances, `orderOf` and `Subgroup.zpowers`, and the
tactics `group`, `rintro`, `obtain`, `simpa`, `congr`, `classical`, `haveI`.

**The maths.** `G` is a finite group, `H ≤ G` a subgroup. The left coset of `g` is
`gH = {g * h | h ∈ H} = {x | g⁻¹ * x ∈ H}` (the exercise's `coset H g`, a `Finset G`).

1. `|gH| = |H|`: `gH` is the image of `H` under `x ↦ g * x`, which is injective (`coset_card`).
2. `xH = gH ↔ x ∈ gH`: cosets are equal exactly when they share a point (`coset_eq_iff`).
3. Group `G` by the map `x ↦ xH`. The fiber over a coset `c = gH` is `{x | xH = gH} = gH` (by 2), of size
   `|H|` (by 1). So `|G| = ∑_{c} |H| = (number of cosets) · |H|`, and `|H| ∣ |G|` (`lagrange_finset`).
4. Translate from `Finset` counts to `Nat.card` (`lagrange`), and apply 4 to `H = ⟨g⟩`, whose size is the
   order of `g` (`orderOf_dvd`).

Quotients `G ⧸ H`, indices, group actions and the library's Lagrange are banned: you count cosets yourself.

## How to read an entry

Each entry is one tactic or one lemma used with `rw`/`simp`/`exact`. It says what changes (**goal**,
**context**, or **goal list**), lists the placeholders with their types, then shows the proof state before
and after.

- `Γ ⊢ G` is a proof state: hypotheses `Γ`, goal `G`. A cell shows only the hypotheses that change.
  `∅` means no goal is left.
- `P` is "the rest of your goal" (`P : ℕ → Prop`, `P : Prop → Prop`, `P : G → Prop`). The step changes only
  the part inside `P (…)`, wherever it sits in a larger goal. `Q` is the same for a goal you prove from a
  hypothesis.
- Placeholders are written as Lean binders. `{α : Type}` is any type. A bracket such as `[Group G]` or
  `[Fintype α]` is a requirement on the type (a *type class*); each entry says what it provides.
- Every `⊢` cell is a state Lean reaches in the companion file; `tools/guide_sync.py` checks that.

## Part 1 · `coset_card` (milestone)

Statement: `#(coset H g) = #{x | x ∈ H}`: every left coset has `|H|` elements. Prove it first; Part 3 uses
it. Plan: `have` the equation `coset H g = image (fun x => g * x) {x | x ∈ H}` (prove it by R1, then unfold
with `simp only [coset, …]` and R2–R4, then R5 with R6 + R7 for `→` and R8 + R9 for `←`), rewrite with it,
and count the image with R10 + R11.

**R1 · `ext x`** changes the **goal and the context**. It uses `Finset.ext`: two finsets are equal when they
have the same members. Placeholders: `{α : Type} (s t : Finset α)`. Pick a name not in the context
(`ext y` if `x` is taken).

| Before | After |
|---|---|
| `⊢ s = t` | `x : α ⊢ x ∈ s ↔ x ∈ t` |

**R2 · `Finset.mem_filter`** changes the **goal**: `a ∈ filter p s ↔ a ∈ s ∧ p a`. Placeholders:
`{α : Type} (s : Finset α) (p : α → Prop) [DecidablePred p] (a : α)`.

| Before | After |
|---|---|
| `⊢ P (a ∈ filter p s)` | `⊢ P (a ∈ s ∧ p a)` |

**R3 · `Finset.mem_univ`, then `true_and`** change the **goal**: `a ∈ univ` is `True`, and `True ∧ q` is `q`.
Placeholders: `{α : Type} [Fintype α] (p : α → Prop) (a : α)`. With R2 this turns `a ∈ {x | p x}` into
`p a`; `simp only [coset, mem_filter, mem_univ, true_and]` does all of it in one call.

| Before | After `simp only [Finset.mem_univ]` | After `simp only [true_and]` |
|---|---|---|
| `⊢ P (a ∈ univ ∧ p a)` | `⊢ P (True ∧ p a)` | `⊢ P (p a)` |

**R4 · `Finset.mem_image`** changes the **goal**: `b ∈ image f s ↔ ∃ a ∈ s, f a = b`. Placeholders:
`{α β : Type} [DecidableEq β] (f : α → β) (s : Finset α) (b : β)`.

| Before | After |
|---|---|
| `⊢ P (b ∈ image f s)` | `⊢ P (∃ a ∈ s, f a = b)` |

**R5 · `constructor`** on `↔` changes the **goal list**: one goal per direction. Placeholders: `(A B : Prop)`.

| Before | After |
|---|---|
| `⊢ A ↔ B` | `⊢ A → B`, `⊢ B → A` |

**R6 · `refine ⟨w, hw, ?_⟩`** changes the **goal**: it supplies the witness `w` and the membership proof
`hw`, leaving the property. Placeholders: `{α : Type} (s : Finset α) (q : α → Prop) (w : α) (hw : w ∈ s)`.
For the coset the witness of `x ∈ g · H` is `g⁻¹ * x`. With all three parts known, `exact ⟨w, hw, proof⟩`.

| Before | After |
|---|---|
| `⊢ ∃ a ∈ s, q a` | `⊢ q w` |

**R7 · `group`** **closes** an equation that holds in every group: it normalises `*`, `⁻¹`, `1` and integer
powers. Placeholders: `{G : Type} [Group G] (a b : G)`. It does not use hypotheses, and it does not prove
membership goals `… ∈ H`.

| Before | After |
|---|---|
| `⊢ (a * b)⁻¹ * a = b⁻¹` | ∅ |

**R8 · `rintro ⟨y, hy, rfl⟩`** changes the **goal and the context**: it introduces the hypothesis
`∃ a ∈ s, f a = b` and takes it apart in one step. `rfl` uses the equation `f y = b` to replace `b` by `f y`
everywhere. Placeholders: `{α β : Type} (s : Finset α) (f : α → β) (b : β) (Q : β → Prop)`.

| Before | After |
|---|---|
| `⊢ (∃ a ∈ s, f a = b) → Q b` | `y : α, hy : y ∈ s ⊢ Q (f y)` |

**R9 · `simpa using h`** **closes** the goal: it runs `simp` on both `h` and the goal and then closes the goal
with the simplified `h`. `simp` knows the group cancellation laws (`mul_inv_cancel_right`, R17, …).
Placeholders: `{G : Type} [Group G] (H : Subgroup G) (a y : G)`.

| Before | After |
|---|---|
| `h : y * a * a⁻¹ ∈ H ⊢ y ∈ H` | ∅ |

**R10 · `Finset.card_image_of_injective`** changes the **goal**: `Injective f → #(image f s) = #s`. Write
`rw [Finset.card_image_of_injective s hf]` (or `_` for `s`). Placeholders:
`{α β : Type} [DecidableEq β] (s : Finset α) (f : α → β) (hf : Function.Injective f)`.

| Before | After |
|---|---|
| `⊢ P #(image f s)` | `⊢ P #s` |

**R11 · `mul_right_injective a`** proves `Function.Injective (fun x => a * x)`: left multiplication by `a` is
injective (cancel `a⁻¹`). The name says "the function is injective in the right argument". Use it as the `hf`
of R10. Placeholders: `{G : Type} [Group G] (a : G)`.

| Before | After |
|---|---|
| `⊢ Function.Injective fun x => a * x` | ∅ |

## Part 2 · `coset_eq_iff` (milestone)

Statement: `coset H x = coset H g ↔ x ∈ coset H g`. Prove it before Part 3, which uses it inside `simp`.
Unfold first (`simp only [coset, …]`, R2, R3), then R5:

- `→`: `x` lies in its own coset. After the unfolding, `h` reads `{x_1 | x⁻¹ * x_1 ∈ H} = {x | g⁻¹ * x ∈ H}`,
  so state the fact in that unfolded form, `have : x ∈ univ.filter (fun y => x⁻¹ * y ∈ H)`, and prove it with
  R2, R3, R12 (`simp [H.one_mem]` does all three). Then rewrite it along the equation (R13) and simplify (R9).
- `←`: R1 with a fresh name `y`, unfold again, R5. Each direction is `simpa [mul_assoc] using …` (R9, R16,
  R17) applied to a product of two members of `H` (R14), one of them inverted (R15) for the `←` half. Put the
  coset hypothesis `g⁻¹ * x ∈ H` on the left, so the middle factors meet and cancel: `(g⁻¹ * x) * (x⁻¹ * y)`
  and `(g⁻¹ * x)⁻¹ * (g⁻¹ * y)`.

**R12 · `inv_mul_cancel`, then `Subgroup.one_mem`** change the **goal**, then **close** it.
`inv_mul_cancel : a⁻¹ * a = 1`, `H.one_mem : 1 ∈ H`. `simp [H.one_mem]` does both. Placeholders:
`{G : Type} [Group G] (H : Subgroup G) (a : G)`.

| Before | After `rw [inv_mul_cancel]` | After `exact H.one_mem` |
|---|---|---|
| `⊢ a⁻¹ * a ∈ H` | `⊢ 1 ∈ H` | ∅ |

**R13 · `rw [h] at hx`** changes the **context**: it rewrites the hypothesis `hx` with `h : a = b`, and the
goal is untouched. Placeholders: `{α : Type} (a b : α) (Q : α → Prop)`.

| Before | After |
|---|---|
| `hx : Q a ⊢ Q b` | `hx : Q b ⊢ Q b` |

**R14 · `Subgroup.mul_mem`** changes the **context** (used with `have`): `H.mul_mem hx hy : x * y ∈ H` from
`hx : x ∈ H`, `hy : y ∈ H`. Placeholders: `{G : Type} [Group G] (H : Subgroup G) (x y : G)`.

| Before | After `have hxy := H.mul_mem hx hy` |
|---|---|
| `hx : x ∈ H, hy : y ∈ H ⊢ x * y ∈ H` | `hxy : x * y ∈ H ⊢ x * y ∈ H` |

**R15 · `Subgroup.inv_mem`** changes the **context**: `H.inv_mem hx : x⁻¹ ∈ H` from `hx : x ∈ H`. Nest it:
`H.mul_mem (H.inv_mem hx) hy : x⁻¹ * y ∈ H`. Placeholders: `{G : Type} [Group G] (H : Subgroup G) (x : G)`.

| Before | After `have hi := H.inv_mem hx` |
|---|---|
| `hx : x ∈ H ⊢ x⁻¹ ∈ H` | `hi : x⁻¹ ∈ H ⊢ x⁻¹ ∈ H` |

**R16 · `mul_assoc`** changes the **goal**: `a * b * c = a * (b * c)`. `*` groups to the left, so
`a * b * c` is `(a * b) * c`. In `simp [mul_assoc]` it pushes every product to the right, which puts
`x * (x⁻¹ * y)` next to each other for R17. Placeholders: `{G : Type} [Group G] (a b c : G)`.

| Before | After |
|---|---|
| `⊢ P (a * b * c)` | `⊢ P (a * (b * c))` |

**R17 · `mul_inv_cancel_left`** changes the **goal**: `a * (a⁻¹ * b) = b`. `simp` uses it (and
`inv_mul_cancel_left : a⁻¹ * (a * b) = b`) by itself. Placeholders: `{G : Type} [Group G] (a b : G)`.

| Before | After |
|---|---|
| `⊢ P (a * (a⁻¹ * b))` | `⊢ P b` |

**W4.** `ha : a * b ∈ H`, `hc : c * b ∈ H` give `a * c⁻¹ ∈ H`: `have h := H.mul_mem ha (H.inv_mem hc)`, then
`simpa [mul_assoc] using h` (`(c * b)⁻¹ = b⁻¹ * c⁻¹`, regroup, cancel `b * b⁻¹`):

```lean-goal
⊢ a * c⁻¹ ∈ H
```

## Part 3 · `lagrange_finset` (milestone)

Statement: `#{x | x ∈ H} ∣ Fintype.card G`. Uses Parts 1 and 2. Steps: R18 and R19 with `f := coset H`,
`s := univ`, so the goal is `#{x | x ∈ H} ∣ ∑ b ∈ image (coset H) univ, #{a | coset H a = b}`. Then `have`
the fiber fact `hfib : ∀ c ∈ image (coset H) univ, #{x | coset H x = c} = #{x | x ∈ H}` (R20, then
`rw [← coset_card H g]`, R21, R1, `simp [coset_eq_iff]`), and finish with R22, R23.

**R18 · `rw [← Finset.card_univ]`** changes the **goal**. The lemma is `#univ = Fintype.card α`; right to left
it turns the type's size into the size of the finset `univ`, so finset lemmas apply. Placeholders:
`{α : Type} [Fintype α]`.

| Before | After |
|---|---|
| `⊢ P (Fintype.card α)` | `⊢ P #univ` |

**R19 · `Finset.card_eq_sum_card_image f s`** changes the **goal**:
`#s = ∑ b ∈ image f s, #{a ∈ s | f a = b}`, i.e. count `s` fiber by fiber of `f`. Give `f` and `s`
explicitly: with `rw`, the left side `#s` matches every card in the goal. Placeholders:
`{α β : Type} [DecidableEq β] (f : α → β) (s : Finset α)`. With `s = univ` the fiber prints as
`#{a | f a = b}`.

| Before | After |
|---|---|
| `⊢ P #s` | ⊢ P (∑ b ∈ image f s, #({a ∈ s \| f a = b})) |

The After state as Lean prints it:

```lean-goal
⊢ P (∑ b ∈ image f s, #({a ∈ s | f a = b}))
```

**R20 · `obtain ⟨a, -, rfl⟩ := Finset.mem_image.mp hc`** changes the **context**: `hc : c ∈ image f s` says
`c = f a` for some `a ∈ s`. `.mp` turns R4's `↔` into `→`; `-` drops `a ∈ s`; `rfl` replaces `c` by `f a`.
Placeholders: `{α β : Type} [DecidableEq β] (f : α → β) (s : Finset α) (c : β) (Q : β → Prop)`.

| Before | After |
|---|---|
| `hc : c ∈ image f s ⊢ Q c` | `a : α, hc : f a ∈ image f s ⊢ Q (f a)` |

**R21 · `congr 1`** changes the **goal**: an equation `f u = f v` becomes `u = v`; here `#s = #t` becomes
`s = t`. It closes the new goal by itself when that is `rfl` or a hypothesis. Placeholders:
`{α : Type} (s t : Finset α)`.

| Before | After |
|---|---|
| `⊢ #s = #t` | `⊢ s = t` |

**R22 · `Finset.sum_const_nat hf`** changes the **goal**: with `hf : ∀ x ∈ s, f x = m`,
`∑ x ∈ s, f x = #s * m`. Placeholders: `{α : Type} (s : Finset α) (f : α → ℕ) (m : ℕ)`. `f` must match the
summand: state `hfib` with the fiber exactly as R19 printed it (bound-variable names may differ).

| Before | After |
|---|---|
| `⊢ P (∑ x ∈ s, f x)` | `⊢ P (#s * m)` |

**R23 · `dvd_mul_left a b`** **closes** `a ∣ b * a` (`b * a = a * b`, witness `b`). Placeholders: `(a b : ℕ)`.
Its twin `dvd_mul_right a b : a ∣ a * b`.

| Before | After |
|---|---|
| `⊢ a ∣ b * a` | ∅ |

**W2: the same count on `Fin 6`.** `f n = n % 3` has three fibers of size 2. R18, R19, then `hfib` by
`decide`, R22, R23:

```lean-goal
⊢ 2 ∣ Fintype.card (Fin 6)
⊢ 2 ∣ ∑ b ∈ image (fun n => ↑n % 3) univ, #{a | ↑a % 3 = b}
⊢ 2 ∣ #(image (fun n => ↑n % 3) univ) * 2
```

## Part 4 · `lagrange`

Statement: `Nat.card ↥H ∣ Nat.card G` for `[Finite G]`. There is no `Fintype` and no `DecidablePred`, so
Part 3 cannot be applied yet. Steps: R24, R25, then R26 twice (once for `↥H`, once for `G`), R27, and
`exact lagrange_finset H`.

**R24 · `classical`** changes neither goal nor context visibly: for the rest of the proof every proposition is
decidable, so `filter p` works for any `p` and the instance `Fintype ↥H` exists. Put it first. Placeholders:
`{α : Type} [Fintype α] (p : α → Prop)`.

| Before | After |
|---|---|
| `⊢ ∃ s, ∀ (x : α), x ∈ s ↔ p x` | `⊢ ∃ s, ∀ (x : α), x ∈ s ↔ p x` |

**R25 · `haveI := Fintype.ofFinite α`** changes the **context**: it adds an instance `this : Fintype α`
built from `[Finite α]`, so `univ` and `Fintype.card α` make sense. `haveI` makes it available to instance
search at once. Placeholders: `{α : Type} [Finite α]`.

| Before | After |
|---|---|
| `⊢ ∃ s, ∀ (x : α), x ∈ s` | `this : Fintype α ⊢ ∃ s, ∀ (x : α), x ∈ s` |

**R26 · `Nat.card_eq_fintype_card`** changes the **goal**: `Nat.card α = Fintype.card α`. One `rw` rewrites one
type; repeat it for a second type. Placeholders: `{α : Type} [Fintype α]`.

| Before | After |
|---|---|
| `⊢ P (Nat.card α)` | `⊢ P (Fintype.card α)` |

**R27 · `Fintype.card_subtype`** changes the **goal**: `Fintype.card {x // p x} = #{x | p x}`, the size of a
subtype is the size of the matching filter of `univ`. `↥H` is `{x // x ∈ H}`, so this turns
`Fintype.card ↥H` into `#{x | x ∈ H}`. Placeholders: `{α : Type} [Fintype α] (p : α → Prop) [DecidablePred p]`.

| Before | After |
|---|---|
| `⊢ P (Fintype.card { x // p x })` | ⊢ P #{x \| p x} |

The After state as Lean prints it:

```lean-goal
⊢ P #{x | p x}
```

**W3: `Finite` to `Finset` in one chain** (R24 → R25 → R26 twice → R27), on `Nat.card {x // p x} ≤ Nat.card α`:

```lean-goal
⊢ Nat.card { x // p x } ≤ Nat.card α
⊢ #{x | p x} ≤ Fintype.card α
```

## Part 5 · `orderOf_dvd`

Statement: `orderOf g ∣ Nat.card G`. The order of `g` is the size of the cyclic subgroup it generates (R28);
then apply Part 4 to that subgroup.

**R28 · `rw [← Nat.card_zpowers]`** changes the **goal**. The lemma is
`Nat.card ↥(Subgroup.zpowers a) = orderOf a`; right to left it turns the order into a subgroup's size.
Placeholders: `{G : Type} [Group G] (a : G)`.

| Before | After |
|---|---|
| `⊢ P (orderOf a)` | `⊢ P (Nat.card ↥(Subgroup.zpowers a))` |

## Traps

- `{x | x ∈ H}` after `#` is a **finset** (`filter (· ∈ H) univ`), not a `Set`. Finset lemmas
  (`Finset.mem_filter`, R2) apply, set lemmas do not.
- Unfold `coset` before anything else (`simp only [coset, …]`): `rw [Finset.mem_filter]` does not see through
  the name.
- `ext x` when `x` is already in the context (in `coset_eq_iff`) gives a shadowed `x_1`-style mess: write
  `ext y`.
- In `coset_eq_iff (→)`, membership in the own coset needs `x⁻¹ * x ∈ H`, i.e. R12; `simp [H.one_mem]` closes
  it after unfolding.
- In `coset_eq_iff (→)`, `have : x ∈ coset H x` does not work with `rw [h] at this`: `h` is already unfolded
  (`{x_1 | x⁻¹ * x_1 ∈ H} = …`) and `rw` does not see through the name `coset`, so it reports "did not find an
  occurrence of the pattern". State the `have` unfolded: `x ∈ univ.filter (fun y => x⁻¹ * y ∈ H)`.
- `H.mul_mem hy hx` instead of `H.mul_mem hx hy` gives `x⁻¹ * y * (g⁻¹ * x)`, where nothing cancels: the order
  of the factors matters in a group.
- `rw [Finset.card_eq_sum_card_image]` without arguments rewrites the first `#…` it finds, maybe `#{x | x ∈ H}`.
  Give `(coset H) univ` explicitly (R19), after `rw [← card_univ]` (R18).
- `Finset.sum_const_nat` needs the fiber function written the way R19 produced it; copy it from the infoview into
  `hfib`.
- In `lagrange`, call `classical` **before** `haveI := Fintype.ofFinite G` and the rewrites: without it there is
  no `Fintype ↥H` and R26 fails on `Nat.card ↥H`.
- `rw [Nat.card_eq_fintype_card]` rewrites one type at a time; you need it twice.
- Quotients `G ⧸ H`, `Subgroup.index`, group actions, complements, the additive twins and the library's
  Lagrange (`Subgroup.card_subgroup_dvd_card`, `orderOf_dvd_card`, …) are banned, as are `exact?`/`apply?`.
  You need none of them.
