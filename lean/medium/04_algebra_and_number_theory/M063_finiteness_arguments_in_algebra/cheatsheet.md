# M063 · Finiteness arguments in algebra: cheatsheet

Exercise: [`problem.lean`](problem.lean).
Lean companion: [`guide.lean`](guide.lean). Entry **Rn** here is
example **Rn** there. Put the cursor after each tactic to see the same before and after states in the
infoview. Generic tactics are in [`TACTIC_STATES.md`](../../../TACTIC_STATES.md).

**Assumed:** Lean basics (easy tier E001–E033). **New here:** Mathlib's algebraic type classes
(`CommRing`, `IsDomain`, `Group`, `Finite`, `Nontrivial`), the cardinality `Nat.card`, subgroups
(`Subgroup`, `⊥`, `⊤`, `Subgroup.zpowers`), Lagrange's theorem and `IsCyclic`.

## How to read an entry

Each entry is one tactic or one lemma. It says what changes (**goal**, **context**, or **goal list**),
gives the lemma's statement, lists the placeholders with their types, then shows the proof state before
and after.

- `Γ ⊢ G` is a proof state: hypotheses `Γ`, goal `G`. A cell shows only the hypotheses that matter.
  `∅` means no goal is left.
- `P : Prop` is "a goal you do not care about": the entry only shows what it adds to the context.
  `Q : ℕ → Prop` is "the rest of a goal" around the part that changes.
- Placeholders are written as Lean binders. `{α : Type}` is any type. A bracket such as `[Group G]` is a
  requirement on the type (a *type class*): here, "`G` carries a group structure". Each entry says which
  familiar types meet it.
- Every `⊢` cell is a state Lean reaches in the companion file; `tools/guide_sync.py` checks that.

## Reading the goals

| You see | It means |
|---|---|
| `{R : Type*}`, shown as `R : Type u_1` | `R` is any type; `Type*` lets it live in any universe `u_1` (ignore the universe) |
| `[CommRing R]` | `R` has `+`, `-`, `*`, `0`, `1` with the commutative-ring laws (ℤ, ℚ, ℝ, `ZMod n`) |
| `[IsDomain R]` | no zero divisors: `a * b = 0 → a = 0 ∨ b = 0`, and `0 ≠ 1` (ℤ, any field, `ZMod p` for prime `p`) |
| `[Finite R]` | `R` has finitely many elements (no explicit list attached; contrast `Fintype`) |
| `[Group G]` | `G` has `*`, `1`, `⁻¹` with the group laws, written multiplicatively |
| `Nat.card α : ℕ` | the number of elements of `α` (`0` if `α` is infinite) |
| `Nontrivial α` | `α` has two distinct elements; the class that lemmas such as `exists_ne` need |
| `Function.Injective f` | `∀ x y, f x = f y → x = y` (R1) |
| `Function.Injective fun x => a * x` | `Function.Injective (fun x => a * x)`: Lean drops the parentheses around a final `fun` argument |
| `Function.Surjective f` | `∀ y, ∃ x, f x = y` (R4) |
| `fun x => a * x` | the map `x ↦ a * x`; `(fun x => a * x) b` is the same as `a * b` (R5) |
| `f ∘ g` | composition, `(f ∘ g) x = f (g x)` |
| `Nat.Prime p` | `p` is prime (written `p.Prime` in source) |
| `m ∣ n` | `m` divides `n` (typed `\mid`, not the ASCII bar) |
| `H : Subgroup G` | a subgroup of `G`, a bundled set closed under `*`, `1`, `⁻¹` |
| `↥H` | `H` used as a type (its elements, with their proofs of membership); appears in `Nat.card ↥H` |
| `⊥`, `⊤` (subgroups) | the trivial subgroup `{1}` and the whole group `G` |
| `Subgroup.zpowers g` | the subgroup `{g ^ k \| k : ℤ}` generated by `g` (R10) |
| `IsCyclic G` | some single `g` generates `G` (R17) |
| `g ≠ 1` | `¬ (g = 1)` |
| `inst✝ : Finite α`, `inst✝¹`, `inst✝²` | unnamed instance arguments from `[…]` binders; the superscripts only tell them apart |
| `this : Nontrivial G` | the fact added by `haveI : Nontrivial G := …` (R8); `this` is the default name |
| `case inl`, `case inr` | the two goals after splitting `A ∨ B`: left case, right case |

## Part 1 · `domain_inv`

Statement: in a finite integral domain `R`, every `a ≠ 0` has a right inverse `b` with `a * b = 1`.
Idea: `x ↦ a * x` is injective (cancellation, R2). A finite set has no injective non-surjective self-map
(R3), so `1` is hit (R4), which is the witness (R5).

**R1 · `intro x y hxy` on `Function.Injective f`** changes the **goal and the context**.
`Function.Injective f` unfolds to `∀ x y, f x = f y → x = y`, so `intro` opens it. In term mode the same
step is `fun x y hxy => …`. Placeholders: `{α β : Type} (f : α → β)`.

| Before | After |
|---|---|
| `⊢ Function.Injective f` | `x y : α, hxy : f x = f y ⊢ x = y` |

When `f` is `fun x => a * x`, Lean shows `hxy : (fun x => a * x) x = (fun x => a * x) y`; lemmas accept it
as `a * x = a * y` anyway (R5).

**R2 · `mul_left_cancel₀`** changes the **goal**. Statement: `mul_left_cancel₀ : a ≠ 0 → a * b = a * c → b = c`.
`apply mul_left_cancel₀ ha` leaves the product equation to prove; `mul_left_cancel₀ ha hxy` closes it at once.
Placeholders: `{R : Type} [CommRing R] [IsDomain R] (a b c : R) (ha : a ≠ 0)`. (Mathlib states it for any
`[IsLeftCancelMulZero M₀]`, which every integral domain is.)

| Before | After |
|---|---|
| `ha : a ≠ 0 ⊢ b = c` | `ha : a ≠ 0 ⊢ a * b = a * c` |

**R3 · `Finite.injective_iff_surjective`** changes the **context** (with `have … := ….mp …`).
Statement: `[Finite α] {f : α → α} : Function.Injective f ↔ Function.Surjective f`. `.mp` is the `→`
direction of an `↔`. Placeholders: `{α : Type} [Finite α] (f : α → α)`; the map must go from a type to the
same type.

| Before | After |
|---|---|
| `hinj : Function.Injective f ⊢ P` | `hs : Function.Surjective f ⊢ P` |

**R4 · `obtain ⟨x, hx⟩ := hs y`** changes the **context**. `hs : Function.Surjective f` is a function
`∀ y, ∃ x, f x = y`: apply it to the point `y`, then take the `∃` apart into a witness and its property.
Placeholders: `{α β : Type} (f : α → β) (y : β)`.

| Before | After |
|---|---|
| `hs : Function.Surjective f ⊢ P` | `x : α, hx : f x = y ⊢ P` |

**R5 · `exact ⟨w, hw⟩`** **closes** an `∃` goal. `⟨w, hw⟩` is the anonymous constructor: witness `w`, proof
`hw` of the property at `w`. `hw` may still show a `fun` applied to `w`; Lean β-reduces when it compares.
Placeholders: `{α β : Type} [Add β] (g : α → β) (c : β) (w : α)`.

| Before | After |
|---|---|
| `hw : (fun x => g x + g x) w = c ⊢ ∃ y, g y + g y = c` | ∅ |

## Part 2 · `prime_order_cyclic`

Statement: a finite group `G` with `Nat.card G = p`, `p` prime, is cyclic.
Idea: `p > 1`, so `G` has some `g ≠ 1` (R6–R9). By Lagrange (R11), `|⟨g⟩|` divides `p`, so it is `1` or `p`
(R12, R13). Size `1` forces `g = 1`, a contradiction (R14–R16). Size `p` forces `⟨g⟩ = G` (R17–R19).
Here `⟨g⟩` is math shorthand for `Subgroup.zpowers g`.

**R6 · `Nat.Prime.one_lt`** changes the **context**. Statement: `p.Prime → 1 < p`; written `hp.one_lt`
(dot notation: `hp : Nat.Prime p`, so `hp.one_lt` means `Nat.Prime.one_lt hp`). Placeholders: `(p : ℕ)`.

| Before | After |
|---|---|
| `hp : Nat.Prime p ⊢ P` | `h1 : 1 < p ⊢ P` |

**R7 · `h ▸ e`** **closes** a goal (as a term it builds a proof of the expected type). With `h : a = b` and
`e : Q b`, `h ▸ e : Q a`: Lean rewrites with `h` in whichever direction makes `e` fit. Same effect as
`rw [h]; exact e`. It needs the expected type to be known (after `exact`, `:=` with a type, or as a function
argument). Placeholders: `(Q : ℕ → Prop) (a b : ℕ)`.

| Before | After |
|---|---|
| `h : a = b, e : Q b ⊢ Q a` | ∅ |

**R8 · `Finite.one_lt_card_iff_nontrivial`** with `haveI` changes the **context**. Statement:
`[Finite α] : 1 < Nat.card α ↔ Nontrivial α`. `haveI : Nontrivial α := ….mp hc` adds the instance as `this`,
and instance search (the `[…]` brackets of later lemmas) now finds it. Placeholders: `{α : Type} [Finite α]`.

| Before | After |
|---|---|
| `hc : 1 < Nat.card α ⊢ P` | `this : Nontrivial α ⊢ P` |

**R9 · `exists_ne`** with `obtain` changes the **context**. Statement: `[Nontrivial α] (x : α) : ∃ y, y ≠ x`.
Write the point with its type, `exists_ne (1 : G)`, so Lean knows which `1`. Placeholders:
`{G : Type} [Group G] [Nontrivial G]`.

| Before | After |
|---|---|
| `⊢ P` (with `inst✝ : Nontrivial G`) | `g : G, hg : g ≠ 1 ⊢ P` |

**R10 · `Subgroup.zpowers g`** is the subgroup of all integer powers of `g`. Its defining lemma
`Subgroup.mem_zpowers_iff : x ∈ Subgroup.zpowers g ↔ ∃ k, g ^ k = x` (with `k : ℤ`) changes the **goal**.
The exercise never needs membership; this entry is here so that `Subgroup.zpowers g` means something to you.
Placeholders: `{G : Type} [Group G] (g x : G)`.

| Before | After |
|---|---|
| `⊢ x ∈ Subgroup.zpowers g` | `⊢ ∃ k, g ^ k = x` |

**R11 · `Subgroup.card_subgroup_dvd_card`** (Lagrange) changes the **context**. Statement:
`[Group α] (s : Subgroup α) : Nat.card ↥s ∣ Nat.card α`. Pass `_` for `s` when the expected type names it.
Placeholders: `{G : Type} [Group G] (H : Subgroup G)`.

| Before | After |
|---|---|
| `⊢ P` | `hd : Nat.card ↥H ∣ Nat.card G ⊢ P` |

**R12 · `Nat.Prime.eq_one_or_self_of_dvd`** changes the **context**. Statement:
`p.Prime → ∀ m, m ∣ p → m = 1 ∨ m = p`; written `hp.eq_one_or_self_of_dvd m hm` (or `_` for `m`).
Placeholders: `(p m : ℕ) (hm : m ∣ p)`.

| Before | After |
|---|---|
| `hm : m ∣ p ⊢ P` | `h2 : m = 1 ∨ m = p ⊢ P` |

**R13 · `rcases h with h1 | h1`** changes the **goal list and the context**: `h : A ∨ B` is removed and you
get two goals, the first with `h1 : A`, the second with `h1 : B`. The term can be given directly:
`rcases hp.eq_one_or_self_of_dvd _ hd with h1 | h1`. Prove each goal under a `·`. Placeholders: `(A B C : Prop)`.

| Before | After |
|---|---|
| `h : A ∨ B ⊢ C` | `h1 : A ⊢ C`, `h1 : B ⊢ C` |

**R14 · `Subgroup.card_eq_one`** changes the **context**. Statement: `Nat.card ↥H = 1 ↔ H = ⊥`.
Placeholders: `{G : Type} [Group G] (H : Subgroup G)`.

| Before | After |
|---|---|
| `h1 : Nat.card ↥H = 1 ⊢ P` | `hb : H = ⊥ ⊢ P` |

**R15 · `Subgroup.zpowers_eq_bot`** changes the **goal** (with `rw`). Statement: `zpowers g = ⊥ ↔ g = 1`.
In the exercise you use `.mp` on a hypothesis instead: `Subgroup.zpowers_eq_bot.mp hb : g = 1`.
Placeholders: `{G : Type} [Group G] (g : G)`.

| Before | After |
|---|---|
| `⊢ Subgroup.zpowers g = ⊥` | `⊢ g = 1` |

**R16 · `absurd`** **closes** any goal. Statement: `absurd : a → ¬a → b`. Placeholders: `(B : Prop)`,
`(h : g = 1) (hn : g ≠ 1)`.

| Before | After |
|---|---|
| `h : g = 1, hn : g ≠ 1 ⊢ B` | ∅ |

**R17 · `isCyclic_iff_exists_zpowers_eq_top`** changes the **goal**. Statement:
`IsCyclic G ↔ ∃ g, Subgroup.zpowers g = ⊤`. Use it with `rw`, or as `….mpr ⟨g, proof⟩` (`.mpr` is the `←`
direction). Placeholders: `{G : Type} [Group G]`.

| Before | After |
|---|---|
| `⊢ IsCyclic G` | `⊢ ∃ g, Subgroup.zpowers g = ⊤` |

**R18 · `Subgroup.eq_top_of_card_eq`** changes the **goal**. Statement:
`(H : Subgroup G) [Finite ↥H] : Nat.card ↥H = Nat.card G → H = ⊤`. `[Finite ↥H]` is found automatically
from `[Finite G]`. Placeholders: `{G : Type} [Group G] [Finite G] (H : Subgroup G)`.

| Before | After |
|---|---|
| `⊢ H = ⊤` | `⊢ Nat.card ↥H = Nat.card G` |

**R19 · `Eq.trans`, `Eq.symm`** change the **goal**. `h1.trans h2 : a = c` from `h1 : a = b`, `h2 : b = c`;
`h.symm : b = a` from `h : a = b`. So `h1.trans h2.symm : a = c` from `h1 : a = b` and `h2 : c = b`.
Placeholders: `(a b c : ℕ)`.

| Before | After `apply Eq.trans h1` |
|---|---|
| `h1 : a = b, h2 : c = b ⊢ a = c` | `h2 : c = b ⊢ b = c` |

### Worked combinations (W1–W3, on objects that are not the exercise's)

**W1: R3, R4, R5 on `f ∘ f`.** `hf.comp hf : Function.Injective (f ∘ f)`, then:

```lean-goal
⊢ ∃ x, f (f x) = y
```

`hx` arrives as `(f ∘ f) x = y`, and `exact ⟨x, hx⟩` accepts it (R5).

**W2: R7 + R11.** `hn ▸ Subgroup.card_subgroup_dvd_card H` proves

```lean-goal
⊢ Nat.card ↥H ∣ n
```

from `hn : Nat.card G = n`.

**W3: R12, R13, R16.** `rcases hp.eq_one_or_self_of_dvd m hm with h1 | h1`; the case `h1 : m = 1` dies by
`absurd h1 hne`, the case `h1 : m = p` is the goal.

## Traps

- Search tactics (`exact?`, `apply?`, `rw?`, `hint`, `try?`) are banned in the final file. They are fine for
  exploring, but they tend to close the goal with a banned lemma (`isCyclic_of_prime_card`, …), so replace
  what they find by the entries here.
- `Finite.injective_iff_surjective` needs a self-map `α → α` of a `Finite` type; `x ↦ a * x` is `R → R`.
  For a map between two different types it does not apply.
- After R3 and R4 the hypothesis reads `(fun x => a * x) b = 1`, not `a * b = 1`. `exact` accepts it as is
  (R5); `simp only at hb` turns it into `a * b = 1` if you want to `rw` with it.
- `exists_ne 1` alone silently picks `1 : ℕ` (you get `g : ℕ`); write `exists_ne (1 : G)`.
- `h ▸ e` rewrites with `h : Nat.card G = p` only where `Nat.card G` appears in the type of `e` (or of the
  goal). Giving the target type, `have hd : … ∣ p := h ▸ …`, makes the intent explicit.
- `rcases … with h1 | h1` gives two goals: focus each with `·`. Running one tactic after it without `·`
  works only on the first goal.
- `Nat.card` of an infinite type is `0`, so every cardinality lemma here relies on the `[Finite G]` binder.

## Cheatsheet

| Need | Write | Entry |
|---|---|---|
| prove `Function.Injective f` | `fun x y hxy => …` or `intro x y hxy` | R1 |
| cancel a nonzero factor | `mul_left_cancel₀ ha hxy` | R2 |
| injective → surjective (finite, `α → α`) | `Finite.injective_iff_surjective.mp hinj` | R3 |
| a preimage of `y` | `obtain ⟨x, hx⟩ := hs y` | R4 |
| prove `∃ y, Q y` | `exact ⟨w, hw⟩` | R5 |
| `1 < p` from primality | `hp.one_lt` | R6 |
| fit a term after an equation | `h ▸ e` | R7 |
| `Nontrivial α` from `1 < Nat.card α` | `haveI : Nontrivial α := Finite.one_lt_card_iff_nontrivial.mp hc` | R8 |
| an element `≠ 1` | `obtain ⟨g, hg⟩ := exists_ne (1 : G)` | R9 |
| subgroup generated by `g` | `Subgroup.zpowers g` | R10 |
| Lagrange | `Subgroup.card_subgroup_dvd_card _` | R11 |
| divisor of a prime | `hp.eq_one_or_self_of_dvd _ hd` | R12 |
| split `A ∨ B` | `rcases h with h1 \| h1` | R13 |
| card `1` → `⊥` | `Subgroup.card_eq_one.mp h1` | R14 |
| `zpowers g = ⊥` → `g = 1` | `Subgroup.zpowers_eq_bot.mp hb` | R15 |
| contradiction | `absurd h hn` | R16 |
| cyclic ↔ a generator | `isCyclic_iff_exists_zpowers_eq_top.mpr ⟨g, _⟩` | R17 |
| full card → `⊤` | `Subgroup.eq_top_of_card_eq _ hcard` | R18 |
| chain equations | `h1.trans h2.symm` | R19 |
| see the state | infoview | |
