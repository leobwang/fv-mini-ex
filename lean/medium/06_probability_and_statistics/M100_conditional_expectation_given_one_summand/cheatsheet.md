# M100 · Conditional expectation given one summand: cheatsheet

Exercise: [`problem.lean`](problem.lean).
Lean companion: [`guide.lean`](guide.lean). Entry **Rn** here is
example **Rn** there. Put the cursor after each tactic to see the same before and after states in the
infoview. Generic tactics are in [`TACTIC_STATES.md`](../../../TACTIC_STATES.md).

**Assumed:** Lean basics (easy tier E001–E033). **New here:** Mathlib's measure-theoretic probability:
σ-algebras (`MeasurableSpace`), the σ-algebra `σ(X)` generated by a random variable, measurability,
integrability, independence, conditional expectation `μ[f | m]`, and "almost everywhere" equality `=ᵐ[μ]`.

## How to read an entry

Each entry is one tactic or one lemma used with `rw`, `refine`, `have` or `exact`. It says what changes
(**goal**, **context**, or **goal list**), lists the placeholders with their types, then shows the proof
state before and after.

- `Γ ⊢ G` is a proof state: hypotheses `Γ`, goal `G`. A cell shows only the hypotheses that change.
- `P` is "the rest of your goal" (`P : Prop`, or `P : α → Prop` for a goal about some `a : α`). The step
  changes only the part inside `P (…)`, wherever it sits in a larger goal. In a context entry, `P` is the
  untouched goal.
- Placeholders are written as Lean binders. `{Ω : Type}` is any type (the sample space).
  `[mΩ : MeasurableSpace Ω]` is the ambient σ-algebra, found by instance search; `{m m₁ m₂ : MeasurableSpace Ω}`
  are other σ-algebras on the same `Ω`, passed by hand. `(μ : Measure Ω)` is a measure on `mΩ`;
  `[IsProbabilityMeasure μ]` says `μ Ω = 1`.
- A goal containing `μ[f | m]` is shown in a `lean-goal` block (first line before, second line after):
  the `|` would break a table cell.
- Every `⊢` cell and goal line is a state Lean reaches in the companion file; `tools/guide_sync.py`
  checks that.

## Reading the goals

**The mathematics in one paragraph.** A **σ-algebra** on `Ω` is a family of subsets ("events") closed under complement and countable union;
in Lean it is a term of type `MeasurableSpace Ω`, and `mΩ` is the ambient one. For `X : Ω → ℝ`,
`σ(X) = {X⁻¹(B) : B Borel}` is the σ-algebra of events decided by the value of `X`
(`MeasurableSpace.comap X inferInstance`). A function is **`m`-measurable** if preimages of Borel sets
lie in `m`; every function is measurable for the σ-algebra it generates. Given a sub-σ-algebra
`m ≤ mΩ` and an integrable `f`, the **conditional expectation** `μ[f | m]` is the (a.e. unique)
`m`-measurable function whose integral over every event of `m` equals that of `f`: the best guess of
`f` knowing only the events in `m`. Three facts drive the exercise: what is `m`-measurable is known
(`μ[f | m] = f`), what is independent of `m` averages out (`μ[f | m] = E[f]`, a constant), and known
factors pull out (`μ[f g | m] = f · μ[g | m]`). The last two hold only almost everywhere.

| You see | It means |
|---|---|
| `{Ω : Type*}` in the spec, `Ω : Type u_1` in the infoview | `Ω` is a type in any universe; `Type*` makes Lean pick a fresh universe name `u_1`. Treat it as `Type` |
| `MeasurableSpace Ω` | the type of σ-algebras on `Ω` |
| `m ≤ mΩ` | every event of `m` is an event of `mΩ`: `m` is a sub-σ-algebra |
| `MeasurableSpace.comap X inferInstance` | `σ(X)`: preimages under `X` of Borel sets of `ℝ` (`comap` = pull back along `X`) |
| `MeasurableSpace.comap X Real.measurableSpace` | the same `σ(X)`; `Real.measurableSpace` is the Borel σ-algebra that `inferInstance` finds |
| `Measurable X` | preimages of measurable sets are measurable. `Measurable[m] X` means "for `m`"; the infoview prints both as `Measurable X` |
| `StronglyMeasurable X` | a limit of simple functions; for `ℝ`-valued functions the same as measurable. `StronglyMeasurable[m] X` also prints without the `[m]` |
| `Integrable X μ` | `X` is measurable (a.e.) and `∫ \|X\| dμ < ∞` |
| `X ⟂ᵢ[μ] Y` | `ProbabilityTheory.IndepFun X Y μ`: `X` and `Y` are independent under `μ` |
| `Indep m₁ m₂ μ` | the σ-algebras are independent: `μ (A ∩ B) = μ A * μ B` for `A ∈ m₁`, `B ∈ m₂` |
| `μ[f \| m]` | `MeasureTheory.condExp m μ f`, the conditional expectation `E[f \| m]`, a function `Ω → ℝ` |
| `μ[Y]` | `∫ ω, Y ω ∂μ = E[Y]`; the infoview prints it as `∫ (x : Ω), Y x ∂μ` |
| `∫ (x : Ω), f x ∂μ` | the integral of `f` over `Ω` with respect to the measure `μ` (`∂μ` names the measure; `x` is a bound variable). For a probability measure it is `E[f]` |
| `fun x => ∫ (ω : Ω), f ω ∂μ` | the constant function with value `E[f]`; in `h2` it prints `fun x => ∫ (x : Ω), Y x ∂μ`, the inner `x` shadowing the unused outer one |
| `f =ᵐ[μ] g` | `f ω = g ω` for `μ`-almost every `ω` (`Filter.EventuallyEq` along the filter `ae μ`) |
| `f + g`, `f * g` (functions) | pointwise sum / product: `(f + g) ω = f ω + g ω` (R12, R13) |

The spec writes `fun ω => X ω + Y ω`; the lemmas talk about `X + Y`. These are the same function up to
unfolding, so `refine`/`exact` accept one for the other, but `rw` would not.

## Part 1 · `condExp_add_given_first`

Statement: for independent, measurable, integrable `X, Y : Ω → ℝ` on a probability space,
`E[X + Y | σ(X)] = X + E[Y]` almost everywhere.

Plan: collect three facts (`X` is `σ(X)`-measurable; `μ[X | σ(X)] = X`; `μ[Y | σ(X)] =ᵐ E[Y]`), split the
conditional expectation of the sum (R9 through R8), go pointwise (R11) and rewrite (R12 and the facts).

### Measurability with respect to `σ(X)`

**R1 · `Measurable.comap_le`** changes the **context** (with `have`). Statement:
`Measurable X → MeasurableSpace.comap X _ ≤ mΩ`: `σ(X)` is a sub-σ-algebra. Every condExp lemma asks for
this as its `m ≤ mΩ` argument. Write it `hX.comap_le`. Placeholders:
`{Ω : Type} [mΩ : MeasurableSpace Ω] (X : Ω → ℝ) (hX : Measurable X)`.

| Before | After `have hle := hX.comap_le` |
|---|---|
| `⊢ P` | `hle : MeasurableSpace.comap X Real.measurableSpace ≤ mΩ ⊢ P` |

**R2 · `comap_measurable`** changes the **context**. Statement: `comap_measurable X : Measurable[σ(X)] X`
(true by definition of `σ(X)`). Its σ-algebra argument is implicit, so state the type in the `have`.
Placeholders: `{Ω : Type} (X : Ω → ℝ)`. Note the printed `Measurable X` hides `[σ(X)]`.

| Before | After `have hm : Measurable[MeasurableSpace.comap X inferInstance] X := comap_measurable X` |
|---|---|
| `⊢ P` | `hm : Measurable X ⊢ P` |

**R3 · `Measurable.stronglyMeasurable`** changes the **context**: `Measurable[m] f → StronglyMeasurable[m] f`
for `f : Ω → ℝ` (dot notation `hf.stronglyMeasurable`). The condExp lemmas take the strong form.
Placeholders: `{Ω : Type} (m : MeasurableSpace Ω) (f : Ω → ℝ) (hf : Measurable[m] f)`.

| Before | After `have hs := hf.stronglyMeasurable` |
|---|---|
| `hf : Measurable f ⊢ P` | `hs : StronglyMeasurable f ⊢ P` |

Chained: `(comap_measurable X).stronglyMeasurable : StronglyMeasurable[σ(X)] X`.

### Independence as σ-algebras

**R4 · `IndepFun_iff_Indep`** changes the **context** (with `.mp`). Statement:
`IndepFun_iff_Indep f g μ : f ⟂ᵢ[μ] g ↔ Indep σ(f) σ(g) μ`. Placeholders:
`{Ω : Type} [mΩ : MeasurableSpace Ω] (μ : Measure Ω) (X Y : Ω → ℝ) (hXY : X ⟂ᵢ[μ] Y)`.
The three explicit arguments may be `_ _ _`.

| Before | After `have hI := (IndepFun_iff_Indep X Y μ).mp hXY` |
|---|---|
| `hXY : X ⟂ᵢ[μ] Y ⊢ P` | `hI : Indep (MeasurableSpace.comap X Real.measurableSpace) (MeasurableSpace.comap Y Real.measurableSpace) μ ⊢ P` |

**R5 · `Indep.symm`** changes the **context**: `Indep m₁ m₂ μ → Indep m₂ m₁ μ`. Placeholders:
`{Ω : Type} {m₁ m₂ : MeasurableSpace Ω} [mΩ : MeasurableSpace Ω] (μ : Measure Ω) (hI : Indep m₁ m₂ μ)`.

| Before | After `have hI' := hI.symm` |
|---|---|
| `hI : Indep m₁ m₂ μ ⊢ P` | `hI' : Indep m₂ m₁ μ ⊢ P` |

### What comes out, what averages out

**R6 · `condExp_indep_eq`** **closes** the goal (use it in `exact` or as the proof of a `have`). Statement:
`m₁ ≤ mΩ → m₂ ≤ mΩ → StronglyMeasurable[m₁] f → Indep m₁ m₂ μ → μ[f | m₂] =ᵐ[μ] fun _ => ∫ ω, f ω ∂μ`:
if `f` only depends on `m₁` and `m₁` is independent of `m₂`, then conditioning on `m₂` gives the plain
mean. The σ-algebra of `f` is the **first** argument of `Indep`. Placeholders:
`{Ω : Type} {m₁ m₂ : MeasurableSpace Ω} [mΩ : MeasurableSpace Ω] (μ : Measure Ω) [IsProbabilityMeasure μ] (f : Ω → ℝ)`
and the four hypotheses `h₁ h₂ hf hI` in that order. (It also needs `SigmaFinite (μ.trim h₂)`, found
automatically for a probability measure.)

| Before | After `exact condExp_indep_eq h₁ h₂ hf hI` |
|---|---|
| context `hf : StronglyMeasurable f`, `hI : Indep m₁ m₂ μ`; goal as below | no goals |

```lean-goal
⊢ μ[f | m₂] =ᵐ[μ] fun x => ∫ (ω : Ω), f ω ∂μ
```

For `μ[Y | σ(X)]` take `f = Y`, `m₁ = σ(Y)`, `m₂ = σ(X)`: you need `Indep σ(Y) σ(X) μ`, but R4 gives
`Indep σ(X) σ(Y) μ`, hence R5. W1 shows the case where no swap is needed.

**R7 · `condExp_of_stronglyMeasurable`** changes the **goal**: `μ[f | m]` becomes `f`. Statement:
`m ≤ mΩ → StronglyMeasurable[m] f → Integrable f μ → μ[f | m] = f` (a true `=`, so `rw` works, and so does
`simp [h1]` with `h1` this equation). Placeholders:
`{Ω : Type} {m : MeasurableSpace Ω} [mΩ : MeasurableSpace Ω] (μ : Measure Ω) [IsProbabilityMeasure μ] (f : Ω → ℝ) (P : (Ω → ℝ) → Prop)`.

Before, then after `rw [condExp_of_stronglyMeasurable hm hf hfi]`:

```lean-goal
⊢ P μ[f | m]
⊢ P f
```

### Almost-everywhere equalities

**R8 · `Filter.EventuallyEq.trans`** changes the **goal**. Statement: `f =ᵐ[μ] g → g =ᵐ[μ] k → f =ᵐ[μ] k`.
`refine h₁.trans ?_` supplies the first link and leaves the second as the goal. This is how an `=ᵐ` lemma
is applied to the left side of an `=ᵐ` goal. Placeholders:
`{Ω : Type} [mΩ : MeasurableSpace Ω] (μ : Measure Ω) (f g k : Ω → ℝ) (h₁ : f =ᵐ[μ] g)`.

| Before | After `refine h₁.trans ?_` |
|---|---|
| `⊢ f =ᵐ[μ] k` | `⊢ g =ᵐ[μ] k` |

**R9 · `condExp_add`** changes the **goal** (through R8). Statement:
`Integrable f μ → Integrable g μ → ∀ m, μ[f + g | m] =ᵐ[μ] μ[f | m] + μ[g | m]`. The last argument `m`
is explicit; `_` lets Lean read it off the goal. Placeholders:
`{Ω : Type} {m : MeasurableSpace Ω} [mΩ : MeasurableSpace Ω] (μ : Measure Ω) (f g k : Ω → ℝ) (hf : Integrable f μ) (hg : Integrable g μ)`.

Before, then after `refine (condExp_add hf hg m).trans ?_`:

```lean-goal
⊢ μ[f + g | m] =ᵐ[μ] k
⊢ μ[f | m] + μ[g | m] =ᵐ[μ] k
```

**R11 · `filter_upwards [h] with ω hω`** changes the **goal and the context**. An `=ᵐ` goal becomes an
ordinary equation at an arbitrary point `ω`, and each listed `=ᵐ` hypothesis is added in pointwise form,
valid at that `ω` (both hold off a null set, so on its complement). Several hypotheses:
`filter_upwards [h, h'] with ω hω hω'`. Placeholders:
`{Ω : Type} [mΩ : MeasurableSpace Ω] (μ : Measure Ω) (f g : Ω → ℝ) (h : f =ᵐ[μ] g)`.

| Before | After `filter_upwards [h] with ω hω` |
|---|---|
| `h : f =ᵐ[μ] g ⊢ (fun ω => f ω + 1) =ᵐ[μ] fun ω => g ω + 1` | `ω : Ω, hω : f ω = g ω ⊢ f ω + 1 = g ω + 1` |

Applied functions such as `(fun ω => …) ω` are beta-reduced, but a sum of functions stays as
`(f + g) ω`: that is R12's job.

**R12 · `Pi.add_apply`** changes the **goal**. Statement: `(f + g) ω = f ω + g ω`. `simp` applies it by
itself. Placeholders: `{Ω : Type} (f g : Ω → ℝ) (ω : Ω) (P : ℝ → Prop)`.

| Before | After `rw [Pi.add_apply]` |
|---|---|
| `⊢ P ((f + g) ω)` | `⊢ P (f ω + g ω)` |

After R12, `rw [h1, hω]` (or `simp [h1, hω]`) finishes: `h1 : μ[X | σ(X)] = X` rewrites the function
before it is applied, and `hω` rewrites the value at `ω`.

### Worked combinations (W1, W2, on objects that are not the exercise's)

**W1: an independent variable averages out** (R1, R2, R3, R4, R6). For `hZW : Z ⟂ᵢ[μ] W`, condition `Z` on
`σ(W)`. Here R4 already gives `Indep σ(Z) σ(W) μ`, the order R6 wants, so there is no `.symm`:

```lean-goal
⊢ μ[Z | MeasurableSpace.comap W inferInstance] =ᵐ[μ] fun x => ∫ (ω : Ω), Z ω ∂μ
```

closed by `exact condExp_indep_eq hZ.comap_le hW.comap_le hZm ((IndepFun_iff_Indep Z W μ).mp hZW)` with
`hZm := (comap_measurable Z).stronglyMeasurable`.

**W2: chain, go pointwise, rewrite** (R8, R11, R12). From `h₁ : F =ᵐ[μ] f + g` and
`h₂ : g =ᵐ[μ] fun _ => c`:

```lean-goal
⊢ F =ᵐ[μ] fun ω => f ω + c
⊢ f + g =ᵐ[μ] fun ω => f ω + c
⊢ (f + g) ω = f ω + c
```

after `refine h₁.trans ?_`, then `filter_upwards [h₂] with ω hω` (adding `hω : g ω = c`); then
`rw [Pi.add_apply, hω]` closes it.

## Part 2 · `condExp_mul_given_first`

Statement: for independent, measurable `X, Y` with `Y` and `X * Y` integrable,
`E[X Y | σ(X)] = X · E[Y]` almost everywhere. Same plan as Part 1 with pull-out (R10) in place of R9 and
no `h1` (the known factor `X` is already outside). Reuse R1–R6 for `μ[Y | σ(X)] =ᵐ E[Y]` and R3 for
`StronglyMeasurable[σ(X)] X`.

**R10 · `condExp_mul_of_stronglyMeasurable_left`** changes the **goal** (through R8). Statement:
`StronglyMeasurable[m] f → Integrable (f * g) μ → Integrable g μ → μ[f * g | m] =ᵐ[μ] f * μ[g | m]`:
a factor known given `m` comes out of the conditional expectation. Placeholders:
`{Ω : Type} {m : MeasurableSpace Ω} [mΩ : MeasurableSpace Ω] (μ : Measure Ω) (f g k : Ω → ℝ)`.
The hypothesis `hXYi : Integrable (fun ω => X ω * Y ω) μ` of the spec is accepted for
`Integrable (X * Y) μ` (same function).

Before, then after `refine (condExp_mul_of_stronglyMeasurable_left hf hfg hg).trans ?_`:

```lean-goal
⊢ μ[f * g | m] =ᵐ[μ] k
⊢ f * μ[g | m] =ᵐ[μ] k
```

**R13 · `Pi.mul_apply`** changes the **goal**. Statement: `(f * g) ω = f ω * g ω`. `simp` applies it by
itself. Placeholders: `{Ω : Type} (f g : Ω → ℝ) (ω : Ω) (P : ℝ → Prop)`.

| Before | After `rw [Pi.mul_apply]` |
|---|---|
| `⊢ P ((f * g) ω)` | `⊢ P (f ω * g ω)` |

## Traps

- `condExp_add`, `condExp_indep_eq` and `condExp_mul_of_stronglyMeasurable_left` give `=ᵐ`, not `=`:
  `rw` cannot use them. Chain them with `refine (lemma …).trans ?_` (R8) or bring them to a point with
  `filter_upwards` (R11). Only `condExp_of_stronglyMeasurable` (R7) is a real `=`.
- The infoview prints `Measurable X` and `StronglyMeasurable X` without the σ-algebra. `hXm :
  StronglyMeasurable X` in your context may be for `σ(X)` or for `mΩ`; hover over it, or state the type
  in the `have` with `StronglyMeasurable[MeasurableSpace.comap X inferInstance] X`.
- In `condExp_indep_eq` the σ-algebra of the averaged function comes first in `Indep`. Conditioning `Y` on
  `σ(X)` needs `Indep σ(Y) σ(X) μ`, the reverse of what `X ⟂ᵢ[μ] Y` unfolds to (R5).
- `comap_measurable X` has an implicit σ-algebra on `ℝ`; with a bare `have hm := comap_measurable X` Lean
  cannot fill it in. Give the type, or use it directly as an argument (`(comap_measurable X).stronglyMeasurable`
  where the expected type is known).
- `inferInstance` and `Real.measurableSpace` print differently but are the same σ-algebra: `rw [hω]` and
  `simp [hω]` still match.
- `filter_upwards` leaves `(f + g) ω`, not `f ω + g ω`; unfold with R12/R13 (or `simp`) before `rw [hω]`.
